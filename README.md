# Meu Dia

Dashboard pessoal para organizar rotina, hábitos, estudo, treino, alimentação, leitura, sono e tempo livre.

## Stack
- React
- TypeScript
- Vite
- Lucide React
- CSS responsivo
- localStorage para persistência local

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Rotina inicial
O plano começa às 07:00 e reserva 8h de estudo, 1h de academia, 30min de cardio, quatro refeições, 1h de leitura, 8h de sono e um bloco flexível de 2h para trabalho/candidaturas/projetos.

Os check-ins e as anotações são salvos automaticamente no navegador.

## Próximas evoluções

Feito como projeto pessoal de produtividade e também como exercício de desenvolvimento frontend.
